# REST API

Описание эндпоинтов сайта подготовки к собеседованию. Заполняй по мере реализации.

## Health

| Метод | Путь       | Описание               |
|-------|------------|------------------------|
| GET   | `/healthz` | Проверка живости сервиса |

## Теория

| Метод | Путь                | Описание                    |
|-------|---------------------|-----------------------------|
| GET   | `/api/theory`       | Список тем теории           |
| GET   | `/api/theory/{id}`  | Одна тема по id             |

## Вопросы

| Метод | Путь                  | Описание                     |
|-------|-----------------------|------------------------------|
| GET   | `/api/questions`      | Список вопросов (с фильтрами)|
| GET   | `/api/questions/{id}` | Один вопрос по id            |
