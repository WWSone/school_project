# web — фронтенд проекта

Здесь будет UI сайта для подготовки к собеседованию. Backend отдаёт данные
по REST API (папка `internal/handlers`), фронт ходит к нему по HTTP.

Пока решаешь, на чём делать фронт (чистый HTML/JS, React и т.д.) —
кладём файлы сюда. Статику (css, картинки, скрипты) складывай в `assets/`.
